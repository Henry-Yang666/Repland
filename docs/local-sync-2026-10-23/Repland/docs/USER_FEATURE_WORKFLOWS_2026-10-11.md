## 核心端到端工作流

1. 收集：任务 → 新增 → 一句话 → 保存待安排 → 查看详情 → 可选补充时长与截止日。关闭可恢复草稿；未保存不产生任务。
2. 规划：已有任务 → 独立排序，或助手制定计划 → 补可用时间 → 检查缺口、新旧时段与轨道 → 确认 → 查看正式日程。排序、草案、正式计划分别存储。
3. 手动安排：日轨道 → 事项库 → 选任务、日期、轨道、时间 → 校验 → 提交 → 时间块详情。拖动、精确调整和跨轨都遵守保护规则。
4. 执行：任务或时间块 → 主动开始 → 暂停 / 后台 / 冷恢复 → 结束本轮 → 选择结果 → 记录进度与反馈 → 可选预览剩余工作重排。
5. 调整：任务详情 → 延期、替换或更正执行日志 → 保存回执 → 主动查看重排；历史恢复不倒退任务执行事实。
6. 课程：时间设置 → 手动每周课程或 PDF 识别预览 → 核对钟点、节次、周模式 → 确认 → 计划避让。取消预览不新增约束。
7. 个性化：真实执行与明确偏好 → 本地数值快照 → 查看来源与建议资格 → 可选有限 AI 描述 → 用户采纳进入新草案 → 重新确认；不自动更改当前计划。
8. 数据：我的 → 导出 JSON → 系统保存 → 成功回执；清除需明确二次确认。导出文件保留在模拟器 Downloads，不发布当前业务快照。

## 覆盖边界

没有真实手机 / OEM / 平板；没有用户真实课表、扫描件或语音成功转写；未验证全部模型提供方、真实自然到点闹钟与 Doze / 重启矩阵、全部系统文档提供方、TalkBack、所有输入法和所有布局组合。实际执行了现有全部自动化用例并逐项记录现有功能，但不宣称穷尽所有用户输入和设备环境。
